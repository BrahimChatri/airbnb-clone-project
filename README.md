   # AirBnB Clone Project

   ## Project Overview
   This project is a clone of the popular platform **AirBnB**, designed to simulate the key features and functionalities of the website, such as property listing, booking, and user management.

   ## Goals
   - Build a responsive and user-friendly interface
   - Implement CRUD operations for managing properties
   - Integrate user authentication and booking systems
   - Learn how to design a scalable web application

   ## Tech Stack
   - **Backend**: Python (Flask)
   - **Database**: MySQL (or SQLite during development)
   - **Frontend**: HTML, CSS, JavaScript
   - **Deployment**: Heroku (or similar platform)
